Lo que editas aquí se guarda como borrador en este navegador. Tus clientes no lo ven hasta que lo publicas:

  1. Revisa todo con Vista previa.
  2. Pulsa Descargar productos.js.
  3. Reemplaza el archivo data/productos.js de tu sitio con el que descargaste (en GitHub: abre la carpeta data → Add file → Upload files).
  4. En uno o dos minutos tu tienda mostrará los cambios.
